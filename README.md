# Life Science Data Analytics — SQL Project

## About
A comprehensive SQL database project combining 
Hospital Management with Genomics/Gene Variant 
tracking — built by an MSc Human Genetics 
graduate transitioning into Data Engineering.

## Database Structure
- patients — 15 patient records
- doctors — 5 specialist doctors
- appointments — Patient-Doctor meetings
- lab_tests — Diagnostic test results
- medicines — Medicine inventory
- prescriptions — Medicine given to patients
- gene_tests — Gene variant tracking (unique!)
